THE METHOD / NOT A GENERAL CHASE SOLVER

        
Finite by construction.

        

          

            
No invented witnesses

            

              Full rules add facts over existing symbols. Keys quotient symbols;
              two different literal constants cause failure. The bounded domain
              has at most five symbols and 75 possible facts.
            

          

          

            
Vacuity is not a rewrite victory

            

              A literal clash means this target query is unsatisfiable under the
              selected assumptions. Its containment holds vacuously. It does not
              mean every database or the dependency set is inconsistent.
