05 / SCOPE THE CLAIM

        
A proof of set answers. Not a bag rewrite.

        

          

            
One theorem. Two kinds of evidence.

            

              Left ⊆ right means a head-preserving homomorphism
              right → left. It fixes constants and maps every
              source atom to a target atom. A missing map is witnessed by the
              target query's canonical database, with distinct frozen values for
              its variables.
            

            

              The minimization atlas enumerates all nonempty atom subsets,
              rejects lost output variables, and tests a map from the full query
              to each safe subset. The smallest equivalent subsets are minimum
              CQs in this contract.
            

            

              Natural provenance and bag probes use canonical facts f0,f1,...
              and multiplicity2 per base fact. These are concrete contrasts, not
              tests deciding bag equivalence.
